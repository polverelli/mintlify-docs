### Step 1: Create a Lumx account

Head over to [**our dashboard**](https://dashboard.lumx.io) and create your free account.\
Use the Lumx Dashboard to manage projects, API keys, and monitor activity with a UI.

### Step 2: Create your API key

Once logged in, go to **Settings → API keys** and generate a new key for your project.

Your **API key is shown only once**. Copy it immediately and store it securely. Keys are sensitive credentials used to authenticate API requests. If a key is ever exposed, **revoke and rotate** it from the Dashboard.

<Note>
  Keys are environment-scoped (Sandbox vs Production). Use the correct key for the base URL you’re calling.
</Note>

### Step 3: Follow our guides and start moving money

[**Create your first customer**](/guides/individual-onboarding) — Create a customer and run KYC/KYB verification.

[**Create an on-ramp payment**](/guides/on-ramp-transactions) — Move funds from a local bank rail into a stablecoin balance.

[**Set up webhooks**](/get-started/quickstart/setting-up-webhooks) — Subscribe to Lumx webhooks and handle events in your application.
